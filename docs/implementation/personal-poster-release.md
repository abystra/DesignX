# 个人海报首版：实施与验收计划

2026-11-18（America/Los_Angeles）。基于 [完整产品审计](product-readiness-audit.md)，用户已选择首版主线：**模板 / 素材 → 编辑 → 保存 → 导出**。

## 发布目标

个人用户注册后，从模板、自己的图片或空白画布开始，在编辑器修改文字、图片、尺寸和配色，保存并重新打开同一作品，下载真实文件。首页以这条可用路径组织；自动创作作为按服务能力开放的扩展。

首版保留既有多画板 Studio 项目。新海报持久化 `workspaceMode=editor`，列表、搜索和刷新进入同一编辑器；历史项目默认 `studio`。不因调整首页而迁移或重排用户已有作品。

## 本批技术约束

- 在 Codex 工作区开发、构建；测试使用独立本机数据库和临时 S3，不连接生产资源。云依赖接入沿用 `scripts/cloud/access.py`，E2B 开发通道仍默认 chisel。
- 提交并推送后，用 `scripts/cloud/deploy.py` 部署该提交；`designx.velax.cn` 访问服务器版本。迁移 0013 为增加列，老部署代码可忽略它，回滚不删除数据。
- 新样式使用 `src/styles/tokens.css`；首页、创作目录先按 14px 正文、12px 元信息、44px 触控与深珊瑚主操作实现。旧编辑器和素材库整体字号迁移仍属后续工作，不声称全站已达标。
- 模板文档抽到 `src/data/template-design.js`，保留原文档几何与颜色。共享 Renderer 补充明确的 Source Serif 4 字体名称，其中文回退固定为随包 Noto Sans SC，兼容原 Georgia 字体映射。
- `pnpm test:poster` 启动隔离 Web/API/Media/Renderer，覆盖真实浏览器旅程并运行渲染一致性对照。只有“丢失创建响应”场景拦截浏览器响应，服务端创建仍真实执行。
