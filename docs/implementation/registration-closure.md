# 关闭公开注册

2026-11-19（America/Los_Angeles），按用户明确要求关闭公开注册。保留已有普通用户名/密码与旧邮箱账号登录、现有会话、作品、账户设置和改密，不创建通用密码或接入邮件服务。

- `REGISTRATION_ENABLED` 只有精确值 `true` 才开放注册，未配置、`false` 和其他值均关闭。`.env.example` 与首次服务器初始化默认 false；已有生产配置未添加该变量时也关闭。
- `/api/auth/options` 公开读取单一布尔状态，继承 `Cache-Control: no-store`。界面状态未知或读取失败时不展示注册入口，仍允许已有账号登录。
- `POST /api/auth/register` 在输入验证、密码计算、用户/空间/会话创建之前拒绝，返回 HTTP 403 和 `REGISTRATION_CLOSED`。同时覆盖用户名与兼容邮箱方式；仅隐藏按钮无法替代此服务端校验。
- 用户已打开的旧注册表单遇到关闭响应时转回登录并显示原因。重新加载页面隐藏“创建账户”，显示“当前暂不开放注册，请使用已有账号登录”。
- 没有数据库迁移，不修改现有账号密码或注销已有会话。测试入口在隔离数据库显式开启注册以建立夹具，再实际关闭服务器配置验证拒绝和已有账号登录；该开关不是客户端参数，也没有公开修改接口。

需要重新开放时，必须先获得明确的产品指令，再由授权运维修改服务器 `/etc/designx/app.env` 的 `REGISTRATION_ENABLED=true` 并重建 API 容器，确认页面和接口一致。不得因为测试缺少账号而临时开放生产注册。回退到不支持此开关的旧应用会重新暴露注册，应优先前向修复。

类型、单元、账户 API、真实浏览器、生产发布与未验收事项见 [本次证据](registration-closure-evidence-2026-11-19.json)。历史 B2/G1–G7 的注册验收保留为当时记录，当前正式站不再提供公开注册。
