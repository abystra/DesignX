# G6：核心创作界面与可达性

本批以真实模板/图片 → 文字、图片、图层 → 保存重开 → 文件导出为验收线。范围是 Editor、旧 Studio 的应用控件及共用弹窗；不改变用户画板的字体、坐标或颜色，也不声称全站或第三方 Board SDK 已获得无障碍认证。

## 组件与行为

- `components/ui/ModalFrame` 使用原生 dialog 顶层提供背景隔离，统一可访问名称、Tab/Shift+Tab、Escape、焦点恢复与 IME 保护。模板/搜索、Workspace 对话框、导入、Editor 版本/导出、Studio 新创作共用；各业务继续决定关闭后的任务处理。原生 Board 的捕获阶段快捷键也跳过打开的 dialog，避免在弹窗关闭时改变背景面板。
- Editor/Studio 应用控件迁移到共享语义前景/操作 token，普通白字主操作使用深珊瑚；辅助文字至少 12px，编辑字段/动作 14px，窄屏输入 16px。文档内容独立。旧示意“咖啡模板”配色卡改为真实色板，不再暗示更换作品内容。
- Editor 窄屏采用作品名行、可横向滚动的操作栏、单个工具/属性抽屉；保存和导出置前，关键按钮保持 44px。添加文字转入属性抽屉；modeless 抽屉焦点进入/关闭恢复。允许画布滚动，不通过全局隐藏页面横向溢出遮掩布局问题。
- 弹窗按 VisualViewport 可用高度和 safe-area 滚动；格式选项在窄屏保持两列，可滚动到确认动作。应用壳也响应可用高度，物理软键盘尚待设备验收。
- 导出分开显示进度与错误，进行中锁定格式、倍率与透明设置。关闭仅关闭视图，任务继续，可在创作动态查看。取消请求返回后才显示取消；完成已胜出时显示文件已生成。请求响应丢失保留同一幂等键，重试核对原任务。文件完成与浏览器下载请求分别表述，不声称文件已保存到设备。
- Studio 保留对话/画布移动视图，工具条可滚动，能力关闭原因保持可读，避免对整个不可用卡片降低透明度。浮层建立独立层级；过渡限定 opacity/transform，避免隐藏画布里的卡片文字在切换视口时短暂透出。

适用状态已覆盖普通/焦点/选中/禁用、加载/进度、取消/失败/重试和长文本。原有 IndexedDB 草稿、保存冲突、账户、偏好与来源合同保留。

## 验收与边界

具体提交、部署、隔离 API/浏览器、截图、真实文件以及正式域名记录见 `ui-evidence-2026-11-18.json`，以实际执行结果为准。

`DESIGNX_UI_ONLY=true PLAYWRIGHT_BROWSERS_PATH=/workspace/work/ms-playwright corepack pnpm test:poster` 使用独立数据库和临时存储。取消验收只暂停该测试启动的 Renderer 子进程，finally 恢复/清理；响应丢失通过浏览器中断已完成的真实 API 响应，不向生产加入故障开关。

视口矩阵含 1440×1000、1024×768、390×844、320×568、600/850/1100/1450 断点边界以及 720×500（相当于 1440×1000 浏览器 200% 的 CSS 可用面积）。后者并非操作系统文字放大实机证据。Chromium 触控模拟不是物理触控验收。

WebKit 27.2 已下载，容器缺少 `libgtk-4.so.1`、`libgraphene-1.0.so.0`、`libharfbuzz-icu.so.0`、`libmanette-0.2.so.0`、`libhyphen.so.0`、`libGLESv2.so.2`，启动失败；未以 Chromium 替代其结论。物理手机软键盘、Safari 实机和读屏仍待具备设备的验收。没有接入邮件或启用 AI。
