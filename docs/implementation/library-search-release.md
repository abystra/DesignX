# B1：项目与素材资料库的分页和搜索

2026-11-18（America/Los_Angeles）。承接个人海报 A 批，落实审计 F11 的列表读取和 F10 的搜索入口部分；账户恢复、模板运营及 AI 仍按 [总计划](personal-poster-release.md) 单独推进。

## 用户可完成的任务

- 在全部作品、文件夹、最近打开和回收站中查询完整的个人项目库，继续加载更早的作品；名称、更新时间和最近打开排序在服务端执行。
- 全局搜索查询整个项目库，打开方式继续使用持久化的 `workspaceMode`。
- 素材库、收藏、品牌 Logo、创作参考以及旧 Studio 的“我的资产”使用分页查询，不再受浏览器先取 1000 条再筛选的限制。
- 下一页失败时保留已显示条目并重试；首次请求或搜索失败显示错误，不显示“空列表”；切换查询会取消旧请求并拒绝过期响应。
- 项目列表只读取摘要，进入可见区域的卡片才加载真实文档，用共享 Renderer 呈现预览。素材卡片使用已有缩略图 URL。去掉由项目名称猜测的示例海报文案。

## 接口合同

`GET /api/projects/page` 和 `GET /api/assets/page` 返回 `{ items, total, nextCursor }`。默认 24 条，最多 100 条。项目摘要不含 `design` 或长篇 `brief`；首页仅取 3 条。旧数组接口保留供旧客户端兼容，当前产品列表、选择器和上传轮询不再使用它们。

共同参数为 `q`、`limit`、`cursor`。`q` 最多 200 字符、忽略首尾空白、大小写不敏感，按字面子串匹配，`%`、`_`、反斜杠不作为通配符。

项目支持 `sort=updated|name|recent`、`recent=0|1`、`trash=0|1`、`folderId`、`type=all|design|ai`。名称使用数据库 C 排序规则及 ID 排序，保证跨页一致；不承诺拼音排序。素材支持 `favorites=0|1` 和 `status=all|ready`；就绪选择器要求存在不可变版本。

游标包含排序值和 ID，绑定工作区、资源种类及筛选条件。时间保留数据库微秒精度，避免同时间戳漏项。游标是位置，不是授权；列表、计数、单素材读取始终在租户 RLS 下执行。无效或跨条件游标返回 400。计数和当页使用同一 SQL 快照；跨页是实时列表，期间新增/编辑可能改变排序，刷新可重新获取最新顺序。

新增 `GET /api/assets/:id` 供上传状态与指定素材读取，避免轮询整库。文件夹计数由数据库统计全部未删除项目。迁移 `0014_library_pagination.sql` 只增加分页索引，回退旧代码无需删除数据。

分页状态、搜索及选择器使用 `--dx-*` 语义颜色；涉及的列表标题、辅助文字、输入和按钮分别按 20/12/14px 及至少 44px 触控区调整，手机输入至少 16px。手机卡片单列呈现，保留真实画板比例；旧编辑器其他样式不在本批全面迁移。

`pnpm test:api` 新增 6 项资料库集成测试：1105 条项目和素材遍历、微秒/同时间戳、旧内容搜索、字面特殊字符、租户隔离、过滤/计数、游标校验和新增首条记录后的续页。

`pnpm test:poster` 继续运行个人海报旅程，并加入 `tests/e2e/library_journey.mjs`：1006 条项目和素材、加载更多、可恢复失败、快速搜索、深层旧素材到真实海报、Logo/参考版本、旧 Studio 及响应式验收。只有失败与延迟场景拦截浏览器响应；正常数据、数据库、存储、API 和 Renderer 均为本机隔离服务。

验收证据与正式域名复测记录见 [B1 验收证据](library-search-evidence-2026-11-18.json)。规模夹具只写隔离测试数据库；正式域名使用可清理的专用账户及少量真实素材。
